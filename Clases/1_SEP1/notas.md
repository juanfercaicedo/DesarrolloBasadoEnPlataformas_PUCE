## Tipos de Plataformas
1. Web
    - Acceso por navegador
    - Rendmiento medio
    - Portabilidad Alta
    - Dependiente de internet
    - `Ejemplo:` **Google Drive**
2. Escritorio
    - Instalación Local
    - Rendimiento alto
    - Portabilidad baja
    - No depende de internet
    - `Ejemplo:` **AutoCAD**
3. Híbridas
    - Acceso: Navegador + empaquetado
    - Rendimiento medio-alto
    - Portabilidad alta
    - Dependencia de internet parcial
    - `Ejemplo:` **Visual Studio Code**

## Arquitectura Cliente-Servidor
- Parte del cliente se conoce como **Frontend**
- Parte del servidor se conoce como **Backend**
- El cliente se conecta al servidor a través de un protocolo(Por ejemplo internet HTTP/HTTPS)
    - Get
    - Post
    - Delete
    - Patch
